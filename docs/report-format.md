# xTB Lab Harness — 보고서 형식 규격 (Report Harness Spec)

형식 버전: **`report-harness-v1.2`**

## 용어 정책 (한글 우선)

보고서 **표 헤더·상태·순위·점수·섹션 본문**은 가급적 한글로 쓴다. 아래만 영어·약어를 유지한다.

| 유지 (필수) | 이유 |
| --- | --- |
| 후보 **ID** (`combo_cell_chitosan` 등) | manifest·run 디렉터리 키 |
| **xTB**, **GFN2**, **`--opt`**, **`--gfn`** | 도구·CLI 플래그 |
| **E (Eh)**, **μ (D)**, **ΔE (kcal/mol)**, **q⁺/q⁻** | 물리량 기호·단위 |
| **`.xyz`**, 파일 경로 | 입력 형식 |
| **Interaction Energy Proxy** | 방법론 고유명 (필요 시 “상호작용 에너지 proxy” 병기) |
| 에이전트 **내부명** (로그·`debates.json`) | 코드 식별자; §7·§10 본문에서는 한글 차원명 사용 |

**금지:** 사용자-facing 표에 `Candidate`, `Opt`, `Status`, `Rank`, `Final Score`, `run_directory`, `yes`/`no` 등 영어 UI 라벨을 그대로 노출.

### 표준 한글 라벨 (harness 강제)

| 영어 (구 v1.1) | v1.2 한글 |
| --- | --- |
| Candidate | 후보 ID |
| Opt | 최적화 |
| Status / success / failed | 계산 상태 / 성공 / 실패 |
| Rank | 순위 |
| Final Score / score | 최종 점수 / 점수 |
| run_directory | 실행 디렉터리 |
| Electro / Struct / Feas / VarCtrl / Critic | 정전기 / 구조 / 실험 / 변인 / 검증 |
| include / caution / exclude | 포함 / 주의 / 제외 |
| geometry optimization | 기하 최적화 |
| Reference candidate | 기준 후보 |

구현: `src/xtb_lab_harness/reports/labels.py`, `reports/sections.py`, `tools/compare.py`.

## 핵심 원칙: 단일 출처 (No Duplication)

동일 사실·수치·문구는 **한 섹션에만** 본문으로 쓴다. 다른 섹션은 **§번호 참조**만 허용한다.

| 정보 | 단일 출처 | 다른 섹션에서 |
| --- | --- | --- |
| 여과 효율 비주장·xTB 방법 한계 | **§3** | §15·§16은 §3 참조만 |
| 후보 메타(charge, 역할, notes) | **§4** | §12는 ID+한줄 사유만 |
| xTB 수치(E, q, μ) | **§6** | 부록 A(ΔE 포함) |
| 에이전트 차원 점수 | **§10** | §7은 이탈 케이스만 |
| 랭킹·가중치·동점·추천 규칙 | **부록 B** | §9는 표만 |
| 대조군 추천 제외 | **§12-2** | §13·§14는 ID 참조만 |
| Top 3 추천·제작 근거 | **§11** | §13은 주 후보 ID만 |
| 변인 통제 | **§14** | — |
| Safety 면책 | **말미 1회** | 본문 반복 금지 |

**금지:** 동일 disclaimer 2회 이상, §7에 모든 후보 동일 boilerplate summary, §8 전체 토론 전문, §9와 부록 B 가중치 중복.

## 필수 섹션

| § | 제목 | 내용 (중복 최소) |
| ---: | --- | --- |
| 0 | 오케스트레이터 작업 할당 | `task_plan` 있을 때만 |
| 1 | 실험 목적 | objective 전문 (1회) |
| 2 | 핵심 가설 | hypothesis (목적 문장 재복붙 금지 권장) |
| 3 | xTB 계산 범위와 한계 | 범위 표 + 한계 bullet + 비주장 문구 **(유일)** |
| 4 | 후보 물질 목록 | ID, 상대경로 xyz, charge, 역할, notes |
| 5 | xTB Tool 계산 조건 | gfn, `--opt`, 입력 형식 (1줄) |
| 6 | xTB 계산 결과 요약 | **통합 표** (한글 헤더) + 증거 경로 표 |
| 7 | 에이전트 검토 (이탈만) | caution/exclude/concerns 있는 항목만 |
| 8 | 에이전트 토론 요약 | 합의·점수 조정만; 전 라운드 전문 **생략** |
| 9 | 최종 랭킹 | 순위·후보 ID·최종 점수·동점 (E/μ **없음**) |
| 10 | 차원별 평가 요약 | 6차원+최종 표 (한글 차원명) |
| 11 | 추천 Top 3 | B 제작 근거 + §6/§10 참조; C 문구 **절당 1회** |
| 12 | 제외·감점·추천 제외 | 12-1/2/3 간결 bullet |
| 13 | 실험 설계안 | 절차만; 목적·대조군은 §1·§12 참조 |
| 14 | 변인 통제 계획 | Variable Control Agent evidence |
| 15 | 예상 실패 요인 | **실험 실행** 리스크만 (방법론은 §3) |
| 16 | 연구의 한계 | 시스템 한계; §3와 겹치면 "§3 참조" |
| 17 | 후속 연구 | bullet |
| 부록 A | Evidence Table | ΔE 등 §6 보완 수치 (한글 헤더) |
| 부록 B | 점수·랭킹 규칙 | 가중치·동점·대조군·추천 분리 (**유일**) |

## §12-2 대조군 (간결 형식)

```
- **{id}** (순위 {n}, 점수 {s}): 대조군 — {notes 한 줄}. §11 추천 제외, §13 실험 대조 포함.
```

§4에 이미 있는 charge·xyz·지정 근거는 **재기재하지 않음**.

---

## §11 Top 3 (간결 형식)

절 상단 1회: `실제 포집/여과는 실험 검증 필요 (§3).`

각 후보:
```
### 11-{n}. {id} (점수 {s})
- {manifest notes 또는 후보 메모 1줄}
- xTB·차원 점수: §6, §10 참조
```

## §6·부록 A 표 헤더 (v1.2)

§6 본문 표:

```
| 후보 ID | 최적화 | E (Eh) | q⁺ max | q⁻ min | μ (D) | 계산 상태 |
```

```
| 후보 ID | 실행 디렉터리 |
```

부록 A:

```
| 순위 | 후보 ID | 계산 상태 | E (Eh) | ΔE (kcal/mol) | μ (D) | q⁺ max | q⁻ min | 최적화 |
```
